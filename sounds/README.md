# Sound pack

Drop MP3 files in this folder and the game uses them instead of the built-in
synthesized cues. Any file that is missing falls back to the synth, so you can
supply one, some, or all of them.

| file | when it plays |
|---|---|
| `theme.mp3`     | taking the hot seat |
| `suspense.mp3`  | loops under questions from Q11; stops the moment you lock |
| `lock.mp3`      | answer locked |
| `correct.mp3`   | right answer |
| `wrong.mp3`     | wrong answer |
| `padav.mp3`     | crossing ₹10,000 or ₹3,20,000 |
| `win.mp3`       | ₹7 crore |
| `quit.mp3`      | quitting |
| `lifeline.mp3`  | any lifeline used |

These files are gitignored: they stay on your machine and are not published to
the public repo or the live site. Only use audio you have the right to use.
